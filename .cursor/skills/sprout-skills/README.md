# New-idea skills (sprouts)

Pre-limb work under **`../the-sprouts/<slug>/`**:

| Skill | Purpose |
|-------|---------|
| **`new-sprout`** | Create **`brief.md`** only |
| **`find-competition`** | Discover rivals from **`brief.md`** → **`marketing/competitors.md`** |
| **`sprout-competition-analysis`** | Deep dive on named rivals + optional **`competition.html`** |
| **`sprout-prototype`** | Static HTML under **`prototype/`** |
| **`sprout-to-limb`** | Promote a sprout into an active **`limb-*`** repo |
| **`cut-limb-or-sprout`** | Retire a limb or sprout — delete folder + trunk refs |
