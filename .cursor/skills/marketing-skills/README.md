# Marketing skills

- **`marketing-interactive-workflow/`** — Interactive hub: for a given limb, shows when marketing last ran per channel, lists open marketing issues/to-dos, and routes you to the right marketing skill (with suggestions). Start here.

- **`calculate-market-size/`** — TAM/SAM/SOM estimate for a limb or sprout. Persists to `<limb>/the-conversation/marketing/marketSize.md`. Routed from the interactive hub.
- **`aso-skills/`** — App Store Optimization and app marketing skills (`aso-audit`, `aso-keyword-research`, …). Each skill is a folder with `SKILL.md` directly under `aso-skills/`.
- **`product-hunt-skills/`** — Product Hunt launch skills (`ph-launch-prep`, `ph-launch-day`, `ph-post-launch`) plus the `product-hunt-workflow` orchestrator. Persists to `<limb>/the-conversation/marketing/productHuntTodos.md`.
- **`outreach-skills/`** — Blog/influencer/press outreach (`outreach-prospecting`, `outreach-pitch`) plus the `outreach-workflow` orchestrator. Persists to `<limb>/the-conversation/marketing/outreachIssues.md`.
- **`reddit-skills/`** — Reddit targeting + posts (`find-relevant-subreddits`, `generate-posts`) plus the `reddit-workflow` orchestrator. Persists to `<limb>/the-conversation/marketing/redditTodos.md`.
- **`facebook-skills/`** — Facebook group targeting + posts (`find-relevant-groups`, `generate-group-posts`) plus the `facebook-workflow` orchestrator. Persists to `<limb>/the-conversation/marketing/facebookTodos.md`.
- **`tiktok-skills/`** — TikTok content (`viral-tiktok-content`) plus the `tiktok-workflow` orchestrator. Persists to `<limb>/the-conversation/marketing/tiktokTodos.md`.
