# Outreach skills

Skills for blog / influencer / press outreach about an app, segmented by vertical
(pet for the bowl apps, productivity for People Keeper). Output **persists** to the
limb so the list can grow and be tracked over time.

| Skill | What it does |
|-------|--------------|
| [`outreach-workflow`](outreach-workflow) | Orchestrator — runs prospecting → pitch for a named limb; writes to `<limb>/the-conversation/marketing/outreachIssues.md` |
| [`outreach-prospecting`](outreach-prospecting) | Builds a lean 10–20 target list + finds/verifies emails via Hunter.io (free tier, credit-frugal) |
| [`outreach-pitch`](outreach-pitch) | Writes subject lines, the pitch template, personalized examples, one follow-up, and a press-kit blurb |

**Tools:** Hunter.io free plan (50 credits/mo) for contacts; Claude for copy.
