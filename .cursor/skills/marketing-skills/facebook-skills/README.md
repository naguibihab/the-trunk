# Facebook skills

Skills for finding the right Facebook groups for an app and generating native,
rule-respecting posts for each. Low-effort / occasional by design. Output
**persists** to the limb as a trackable to-do list.

| Skill | What it does |
|-------|--------------|
| [`facebook-workflow`](facebook-workflow) | Orchestrator — runs find → generate for a named limb; writes to `<limb>/the-conversation/marketing/facebookTodos.md` |
| [`find-relevant-groups`](find-relevant-groups) | Finds ~8–15 relevant Facebook groups + captures each one's promo rules, join/post gates, and best post type |
| [`generate-group-posts`](generate-group-posts) | Writes one tailored pitch (or participate-only prompt) per group, in that group's voice |

**Golden rules baked in:** give value first, disclose you're the maker, read each
group's rules, and space posts out.
