# Product Hunt skills

Skills for launching an app on Product Hunt. The `product-hunt-workflow`
orchestrator **persists** a trackable plan to
`<limb>/the-conversation/marketing/productHuntTodos.md`; the individual phase
skills produce paste-ready copy you can drop into that file.

| Skill | Phase | What it does |
|-------|-------|--------------|
| [`product-hunt-workflow`](product-hunt-workflow) | orchestrator | Runs the 3 phases below for a named limb |
| [`ph-launch-prep`](ph-launch-prep) | before | Tagline, description, topics, gallery checklist, first comment, timing, pre-launch teaser |
| [`ph-launch-day`](ph-launch-day) | during | Hour-by-hour playbook, ethical engagement rules, reply templates |
| [`ph-post-launch`](ph-post-launch) | after | Repurpose the rank/badge, convert traffic, thank-yous, learnings |

The phases are time-separated — run only the one relevant to where the launch is.
